\begin{abstract}
Valuing the guarantees embedded in variable annuities is computationally expensive because the liability has no closed form and must be estimated by Monte Carlo valuation across many contracts, market states and reporting dates. Deep neural network emulators can approximate this valuation at a fraction of the cost, but existing emulators are trained on values alone, report point estimates only, and discard a resource that the valuation already produces almost for free, namely the sensitivities of the value to the underlying risk factors. This proposal develops a sensitivity augmented deep learning framework for variable annuity guarantee valuation under stochastic mortality. The emulator maps a vector of policy, financial and mortality variables to the present value of the guarantee liability, and is trained jointly on values and their sensitivities, so that it learns the valuation surface and its slopes together. The central claims are, first, that this augmentation raises accuracy and reduces the number of valuations needed for training, and second, that it yields accurate risk sensitivities for hedging as a direct by product. Every prediction is reported with a calibrated confidence interval rather than as a point estimate. All inputs are real, citable data: equity index option prices, implied volatilities and Greeks from Bloomberg, Treasury yield curves from the United States Treasury, variable annuity contract terms from the United States Securities and Exchange Commission Variable Insurance Product Data Sets, and mortality from the Human Mortality Database and Statistics South Africa.
\end{abstract}

\noindent\textbf{Keywords:} variable annuities; deep neural network emulation; differential machine learning; pathwise sensitivities; Greeks; uncertainty quantification; conformal prediction; stochastic mortality.

\section{Introduction}
A variable annuity is a long term savings contract in which the policyholder invests in a reference fund while the insurer provides guarantees such as the guaranteed minimum accumulation, death and withdrawal benefits. These guarantees are options on the fund whose value depends jointly on the account value, interest rates, equity volatility, the policyholder's survival and the contract terms. The value has no closed form, so insurers estimate it by Monte Carlo valuation. Because a large book must be revalued repeatedly, for pricing, hedging and capital, this valuation is a major computational burden.

Neural network emulators address this burden by learning the valuation map once and then evaluating it cheaply across the whole book. This approach is now well established \citep{hejazi2016neural, gan2017efficient}. It has, however, two blind spots. First, the same valuation run that produces the value of a contract can also produce, at almost no extra cost, the sensitivities of that value to the risk factors, through pathwise or adjoint algorithmic differentiation. These sensitivities are exactly the hedging quantities an insurer needs, yet standard emulators are trained on values only and throw this information away. Second, emulators return a single number with no statement of how far it can be trusted.

This proposal addresses both. Training the emulator on values and their sensitivities together is a strong form of regularisation: it pins down the valuation surface with far fewer training points and produces accurate sensitivities directly. This is the principle of differential machine learning \citep{huge2020differential} and Sobolev training \citep{czarnecki2017sobolev}, and it is a natural fit for actuarial valuation, where the sensitivities are both available and wanted. Alongside each value and each sensitivity, the emulator reports a calibrated confidence interval. The setting throughout is stochastic mortality, so that the mortality intensity is a random process rather than a fixed life table, which is more realistic for long dated guarantees.

\section{Existing Work and Research Gap}
Two recent studies frame the project. Li and Lyu \citep{li2026valuation} value variable annuities under a Volterra mortality model combined with rough Heston equity dynamics, and show that a realistic, long memory mortality basis materially changes guarantee values. Langren\'e, Luo, Shevchenko and Zhang \citep{langrene2026deep} develop deep least squares Monte Carlo methods for variable annuities with guarantees, including optimal withdrawal, and report confidence intervals for the value of a contract. Both are per contract solvers: each run values one contract under one set of parameters, and the reported intervals describe Monte Carlo estimator error for that contract.

The emulation literature takes the complementary, portfolio view \citep{hejazi2016neural, gan2017efficient}: a single model maps contract and market characteristics to value across the whole book, but it is trained on values alone and returns point estimates. Differential machine learning \citep{huge2020differential} has shown, for financial derivatives, that training on values and pathwise derivatives together gives large gains in accuracy and data efficiency, but it has not been applied to insurance guarantees, to stochastic mortality, or with calibrated uncertainty.

The gap is therefore specific. There is no variable annuity emulator that is trained jointly on values and sensitivities, that produces hedging sensitivities as a direct output, that reports calibrated intervals on both the value and the sensitivities, and that does so when the mortality basis is itself stochastic and every input is real data.

\section{Research Aim, Objectives and Questions}
\subsection{Aim}
To develop and evaluate a sensitivity augmented deep neural network emulator for variable annuity guarantee valuation under stochastic mortality, delivering higher accuracy at lower computational cost together with calibrated confidence intervals on values and sensitivities, using real market, contract and mortality data.

\subsection{Objectives}
\begin{enumerate}[label=\arabic*.,leftmargin=*]
\item Assemble the real modelling dataset of Section~\ref{sec:data}, linking contract terms, market states and mortality states.
\item Build a valuation engine that returns, for each contract and date, the guarantee value and its sensitivities, calibrated to the real data.
\item Develop the sensitivity augmented emulator and its differential training objective.
\item Quantify its accuracy and data efficiency against a value only emulator of equal capacity.
\item Attach calibrated confidence intervals to values and sensitivities.
\item Evaluate hedging performance of the emulator sensitivities on the observed market history.
\end{enumerate}

\subsection{Research questions}
\begin{enumerate}[label=RQ\arabic*.,leftmargin=*]
\item How much does training on values and sensitivities together improve value accuracy relative to training on values alone, at a fixed training budget?
\item How many fewer training valuations are needed to reach a target accuracy when sensitivities are included?
\item How accurate are the emulator's sensitivities, and are they good enough to hedge?
\item Can calibrated intervals with finite sample coverage be attached to both the value and the sensitivities, and how do they behave in stressed market periods?
\item How sensitive are accuracy and calibration to the choice of stochastic mortality model?
\end{enumerate}

The modelling dataset is constructed directly from these sources. Each record is a real variable annuity product, taken from the SEC filings, evaluated on a real trading date, with the market state observed on that date in Bloomberg and the Treasury data, and the mortality state fitted to the Human Mortality Database for that calendar year. Policyholder age and sex range over the ages and sexes for which the product is offered. The variation in the dataset therefore comes entirely from observed contract terms, observed market history and observed mortality experience.

The equity index option data play a second role. For listed options, Bloomberg reports both the market price and the Greeks, which is exactly the combination of values and sensitivities that the differential emulator needs. These observed pairs are used first, to establish that sensitivity augmentation improves accuracy on purely market data before it is applied to the guarantees.

\section{Methodology}
\subsection{Input vector and response}
Following the structure of the guarantee, the input vector $x$ groups three blocks of variables, listed in Table~\ref{tab:inputs} with their sources.

The response is one continuous value, the present value of the guarantee liability, net of rider fee income,
\begin{equation}
Y(x)=\E^{\Q}\!\left[\text{discounted guarantee cash flows} - \text{discounted fees}\mid x\right],
\end{equation}
and its sensitivities $G(x)=\nabla_x Y(x)$, whose components are the hedging Greeks: delta with respect to the equity level, vega with respect to volatility, rho with respect to the interest rate, and a mortality sensitivity. For each record the valuation engine returns an estimate $\widehat Y_i$ and, by adjoint algorithmic differentiation at the cost of roughly one extra pass, an estimate $\widehat G_i$.

Mortality enters through a stochastic force of mortality $\mu_{x+t}$, with an affine intensity model as the baseline and the Volterra specification of Li and Lyu \citep{li2026valuation} as a robustness check; the Lee and Carter model \citep{lee1992modeling} fitted to the same data provides the mortality trend and cohort inputs. Keeping two specifications separates the emulation question from the choice of mortality model.

\subsection{Sensitivity augmented training}
The emulator $f_\theta$ is a deep feedforward network trained to match both the values and the sensitivities,
\begin{equation}
\mathcal L(\theta)=\frac1n\sum_{i=1}^{n}\Big[\big(f_\theta(x_i)-\widehat Y_i\big)^2
+\sum_{k}\lambda_k\big(\partial_{x_k} f_\theta(x_i)-\widehat G_{i,k}\big)^2\Big],
\label{eq:sobolev}
\end{equation}
where $\partial_{x_k} f_\theta$ is computed by automatic differentiation and the weights $\lambda_k$ balance the value term against each sensitivity term. The second group of terms is what distinguishes this emulator from a standard one. Each training record now supplies one constraint on the value and one on each slope, so the information per record is much larger. This is expected to raise accuracy at a fixed training budget, to reach a target accuracy with fewer valuations, and to give hedging sensitivities that are markedly more stable than those obtained by differentiating a value only fit. Hyperparameters, including the $\lambda_k$, will be tuned on a validation set by Bayesian optimisation, as in the candidate's MSc work.

\subsection{Confidence intervals}
A valuation that drives a reserve or a hedge must come with an honest statement of its reliability, so the emulator does not report point estimates alone. Uncertainty is estimated with deep ensembles \citep{lakshminarayanan2017simple}, and the resulting scale $s(x)$ is calibrated by split conformal prediction \citep{lei2018distribution, romano2019conformalized} on a held out calibration set, giving the interval
\begin{equation}
C_\alpha(x)=\big[f_\theta(x)-q_{1-\alpha}\,s(x),\ f_\theta(x)+q_{1-\alpha}\,s(x)\big],
\end{equation}
which contains the true value with probability at least $1-\alpha$ in finite samples. The same construction is applied to each sensitivity. Calibration is assessed by empirical coverage, interval width and the continuous ranked probability score \citep{gneiting2007strictly}.

\section{Experimental Design and Evaluation}
The method is first validated on the Bloomberg index option data, where the emulator is trained to reproduce the observed option prices and Greeks; this directly tests whether the sensitivity terms in \eqref{eq:sobolev} improve accuracy and data efficiency against a value only emulator of identical architecture. It is then applied to the variable annuity dataset of Section~\ref{sec:data}. Records are split chronologically into training, validation, calibration and test periods, so that every test is out of time on real market history. The evaluation covers:
\begin{itemize}[leftmargin=*]
\item value accuracy: root mean squared and mean absolute error against held out values;
\item sensitivity accuracy: error against held out Greeks and, operationally, the profit and loss of a hedge driven by the emulator sensitivities over the observed market path, following \citep{hull2017optimal};
\item data efficiency: accuracy as a function of the number of training records;
\item uncertainty: empirical and conditional coverage, interval width and proper scores, including in stressed periods such as March 2020;
\item cost: valuation time for the full book relative to the engine.
\end{itemize}

\section{Expected Contributions}
\begin{enumerate}[label=\arabic*.,leftmargin=*]
\item A sensitivity augmented deep neural network emulator for variable annuity guarantees under stochastic mortality.
\item Evidence on the accuracy and data efficiency gains from sensitivity augmentation relative to value only emulation, at matched capacity and budget.
\item Directly learned hedging sensitivities and a demonstration of their use in hedging on real market history.
\item Calibrated confidence intervals on values and sensitivities in place of point estimates.
\item A reproducible real data pipeline linking SEC contract terms, Bloomberg market data and Human Mortality Database mortality, with open code.
\end{enumerate}

\section{Ethics and Reproducibility}
The research uses market data, publicly filed contract terms and population mortality data. It involves no identifiable policyholder information and no human participants. Ethics clearance will be obtained from the University of the Free State before data work begins. All code, data extraction scripts and random seeds will be version controlled so that every result can be reproduced.
